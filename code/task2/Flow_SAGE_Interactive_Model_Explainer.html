How Flow-SAGE Actually Works

Interactive explanation of the graph construction, GraphSAGE message passing, residual feature head, and 10-class prediction.

1 · Pipeline & controls

1Flow → node
Each flow is one node with 29 features.
2Build timelines
Group by source IP and destination IP; sort by time.
3Add edges
Connect each flow to its K nearest-in-time flows on each host timeline. Move the K slider to add/remove edges live.
4GraphSAGE ×2
Aggregate neighbour information at two hops.
5Residual head
Concatenate graph embedding h with original x.
6Prediction
Linear → ReLU → Dropout → 10 class logits.
29flow features
128hidden dimension
2SAGEConv layers
10output classes
